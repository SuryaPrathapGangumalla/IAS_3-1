# ALM-2 — Three Security Projects

This repository contains three independent Flask-based educational prototypes based on the supplied ALM-2 project brief:

1. **CryptoVault** — public-key cryptography and digital signatures
2. **SecureTunnel** — TLS/SSH handshake and IPsec visualizer
3. **Sentinel** — intrusion detection and firewall simulator

Each folder is self-contained and has its own `README.md` and `requirements.txt`. Open a terminal in a project folder, install its requirements, and run `python app.py`. See the individual README files for commands and limitations.

No screenshots are included. Database files are generated locally when the apps run and are excluded from Git.
