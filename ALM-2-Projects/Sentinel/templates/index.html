File-infector virus

Malicious code that attaches to executable files. Defenses include trusted software sources, endpoint protection, and least privilege.

Boot-sector virus

Malware that targets boot records or startup components. Keep systems patched and use secure boot protections where supported.

Email worm

Malware that spreads through messages or attachments. Treat unexpected attachments cautiously, filter mail, and keep software updated.

Bastion host

A hardened, closely monitored host exposed to a less-trusted network, used as a controlled access point.

Rule-based vs anomaly-based IDS

Rule-based detection matches known patterns. Anomaly-based detection flags activity that differs from an observed baseline; it can produce false positives.
